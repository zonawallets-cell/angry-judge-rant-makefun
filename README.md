A short, furious rant about a company-wide reply-all email chain that refuses to die, written for make.fun's Angry Judge contest.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes one rant (311 characters, within the 400-character cap) to `entry.txt` in the output directory. Pure standard library, no dependencies.
